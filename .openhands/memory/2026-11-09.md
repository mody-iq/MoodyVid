## Key design decisions
- One Downloads list for two engines: `MVDownloadRow` wraps `MVDownloadRecord`
  (yt-dlp) and `MVDownloadTask` (manager). The table switches on `row.kind`.
- Un-built engines (HLS, torrent) create an *honest failed row* with a localized
  reason, not a row stuck at 0%. `MVDownloadManager resumeTask:` keeps that true.
- Sniffer probes only genuinely new URLs (store `addItem:` returns BOOL).
- Clipboard banner only *offers*; the pasteboard is read on tap (iOS 16+ prompt).

## CI compile errors found (ObjC API traps)
1. `WKWebView` find is `findString:withConfiguration:completionHandler:` — NOT
   `findString:configuration:completionHandler:`.
2. `NSString` percent-decoding is the method `stringByRemovingPercentEncoding`,
   NOT the `.removingPercentEncoding` property (fails on iOS SDK).
3. `WKContentRuleList` has no `.rules` property — log `.identifier` instead.
