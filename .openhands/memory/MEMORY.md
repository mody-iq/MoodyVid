# MoodyVid memory index
- Build: GitHub Actions; push to main triggers IPA build (`gh run list` to watch). `Sources/*.m` glob picks new files.
- Push needs tokenized remote (GITHUB_TOKEN) — remote gets set with resolved token.
- Player: MVPlayerCenter singleton owns the AVPlayer; floating mini-bar; audio bg mode declared. Full player is a CUSTOM MVFullPlayerViewController (AVPlayerLayer + glass bar), NOT AVKit — AVPlayerViewController pauses its player on dismissal (the "audio stops on shrink" bug). Never transfer the player to another VC; hideFloatingBar/showFloatingBar control the mini bar.
- Files tab plays videos IN a glass card (in-tab), not a modal. AVPlayerLayer shared-player card, 16:9 surface.
- Wallpapers: 10 keys, gradient or raster pattern (`MVTheme.wallpaperUsesImage:`). `CAGradientLayer.colors` takes CGColorRefs — resolve dynamic colors, re-apply via `refreshWallpaperIfPattern:` on trait change. Shell wallpaper lives on MVTabBarController.view; nav controller views MUST be clearColor (else opaque white masks the wallpaper behind the chrome = "wallpaper only in middle").
- Glass: `applyCardStyle:` inserts blur `UIVisualEffectView` (tag `kGlassBlurTag`, userInteractionEnabled NO). Nav/tab bars use transparent+blur appearances.
- Settings: Appearance/Wallpaper rows present action sheets (Language pattern); swatches via `wallpaperSwatchViewForName:`.
- Home brand = `MVGradientLabel` (kCGTextClip gradient text) + glassy badge.
- Python: MVPython startOnQueue imports `downloader` (yt-dlp) at launch so first download doesn't stall.
- Traps: `.CGColor` after `?:` mis-binds → resolve colors into locals first. Big heredoc writes truncate; use file_editor/python.
- Browser (rebuilt 2026-11-09): multi-tab (MVBrowserTab, max 8), home page (MVBrowserHome: shortcuts/bookmarks/history), tab grid (MVTabsViewController), sniffer (MVSnifferScript injected at documentStart + MVSnifferStore per tab + MVMediaProbe HEAD/Range with cookies+referer), ad blocker (MVAdBlocker WKContentRuleList), found-media sheet (MVSnifferSheet). Popups without a user gesture are dropped; magnet links route to the manager.
- Download stack: MVDownloadTask/MVTaskStore (JSON in App Support, atomic, corruption-tolerant), MVDownloadManager (queue: maxConcurrentTasks, maxConnections, speedLimit, wifiOnly), MVFastDownloader (multi-connection segmented: ranged probe → up to `connections` .partN segments in parallel → streamed join off-main; single-connection fallback when the server ignores Range; Range resume + ETag guard + throttle). MVHLSDownloader (m3u8: master→variant, AES-128 CBC, EXT-X-MAP fMP4, MPEG-TS→MP4 remux via AVFoundation; live/SAMPLE-AES fail with a localized reason). MVMPDDownloader (mpd via NSXMLParser: best video rep, SegmentTemplate $Number$/$Time$ + SegmentTimeline, SegmentList, SegmentBase + BaseURL chain; 4-way parallel segment fetch; live/ContentProtection fail with a localized reason). Torrent engine BUILT (Foundation-only core in Sources/MVTorrent*.m + MVBencode/MVSHA1/MVMagnet; peer wire, storage, tracker announce). magnet still refused honestly (BEP 9 later). The two stream engines share `enqueueStreamItem:source:label:` in the manager.
- Downloads tab shows BOTH engines in one list via `MVDownloadRow` (wraps MVDownloadRecord and MVDownloadTask). Adding a new row kind = extend MVDownloadRow + cellForRow.
- CRASH TRAP: the Downloads list mixes two cell classes (MVDownloadCell for records, MVTaskCell for tasks). Never cast a visible cell to one class and call a configure method — dispatch on `row.kind` and send each cell only the selector its own class implements. `main.m` resumes interrupted tasks at launch, so a mistake here aborts on launch and loops (iOS relaunches → resume → abort).
- ObjC API traps hit in CI: `WKWebView findString:withConfiguration:completionHandler:` (NOT `configuration:`); `stringByRemovingPercentEncoding` (NOT `.removingPercentEncoding` property); `WKContentRuleList` has no `.rules`.
- Ad blocker (`MVAdBlocker`): WebKit rejects the WHOLE content-rule list if one rule is invalid (`WKErrorDomain error 6`). Two traps: (1) `if-domain` maps to `IfTopURL` — the **page** URL, not the request — so an ad-host `if-domain` list never blocks requests *to* those hosts; use a `url-filter` matching the request host instead. (2) when a list is refused, `probeRules:` recompiles each rule alone and keeps the accepted ones (`MoodyVidAdsGood`), so one bad rule no longer disables everything. If ads appear, grep the log for `adblock:`. Rules are built at runtime via `NSJSONSerialization` in `MVAdBlockRules()` (an array of single-rule JSON strings), not a hand-escaped literal.
- Side-by-side builds: `scripts/build.sh` reads app identity from env (MV_APP_NAME / MV_BUNDLE_ID / MV_DISPLAY_NAME / MV_ICON_TOP / MV_ICON_BOTTOM) with shipping defaults. Two apps only coexist if their CFBundleIdentifier differs; same id = install replaces. The workflow has a `variant` workflow_dispatch input that builds `com.mody.moodyvid.test` / "MoodyVid Test" / purple icon. `make_icon.py` takes optional r,g,b top/bottom colours.
- Build script `scripts/build.sh` fetches yt-dlp nightly by explicit tag then stable, with a `fetch()` retry helper (upstream 504s made builds red).
- ObjC trap: ANY property whose name starts with `init` (initSegment, initTemplate, initStart…) makes clang read its getter as an init method → rename (mapSegment/mapTemplate/mapStart).
- See daily logs: 2026-11-06.md, 2026-11-09.md, 2026-11-10.md, 2026-11-11.md.
- Pause/resume (yt-dlp engine, 2026-11-11): a pause can't suspend yt-dlp, so it unwinds like a cancel but keeps the `.part` file. `MVPython` gains `pausedTasks` + `mvnative.paused(task)`; `MVDownloadEngine` gains `pauseDownload:`/`resumeDownload:` and treats `"paused"` as an error code that sets `MVDownloadStatePaused` (keeps fragments) instead of Failed. Two traps: (a) a paused merged (1080p+) job must KEEP its `.video` fragment — resuming reuses `existingFragmentFor:marker:` so only the audio is re-fetched; (b) `finishJob:` now bails when `_running[id]` is a *different* job, because a resume can queue a replacement before the paused callback lands (the late callback would otherwise clobber it). `MVDownloadRecord.isActive`/`MVDownloadTask.isActive` include the Paused state.

- yt-dlp page downloads need the LIVE page URL. `tab.url` only updates on `didFinishNavigation`, so a SPA (YouTube) leaves it stale; the sniffer script now reports `location` changes and the download reads `webView.URL`. See `.openhands/memory/2026-11-10.md`.
- YouTube player clients: `android` works (combined mp4); web styles (tv_simply/web_safari/mweb/web_embedded) are bot-blocked. Datacenter IPs are blocked, so device testing matters.
- High quality (>=1080p and "best") = two fragments + native mux, because iOS has no ffmpeg. Fragments are named `.video.`/`.audio.`; the mux/MP3 target MUST differ from its source (`derivedPathFor:` strips the marker and adds `-merged`/`-mp3`) — the old code muxed onto the video file itself and produced an empty result. `+[MVMediaConverter hasAudioTrack:]` skips the audio download when the picture already carries sound. Fragments are tracked in `_fragments` and cleaned on success/failure/cancel. See `.openhands/memory/2026-11-10.md`.
